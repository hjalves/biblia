## O que é

O texto completo da tradução do **Padre Manuel de Matos Soares** (1956): os **73 livros** do cânon católico, em português de Portugal, em **JSON** e em **Markdown**, prontos a usar em apps, sites e estudos.

Partimos de uma digitalização da edição, que foi **toda revista e corrigida**:

- **Novo Acordo Ortográfico** (AO90, como se aplica em Portugal): `Egipto → Egito`, `acção → ação`, `baptismo → batismo`.
- **Português de Portugal**: `demônio → demónio`, `Gênesis → Génesis`, `conosco → connosco`.
- **Erros da digitalização**: acentos antigos, trema, gralhas e versículos repetidos.

O resumo das correções está em [CORRECOES.md](CORRECOES.md).

## Origem

Esta edição é um **trabalho derivado de uma obra em domínio público**: a Bíblia do Padre Manuel de Matos Soares (1956). O texto foi **alterado e corrigido para ficar atualizado**: novo Acordo Ortográfico, formas de Portugal e correção dos erros da digitalização.

> **Como esta versão se destina a uso geral e público, quem a quiser usar tem de referenciar a fonte: este repositório.**

## Usar os dados

| Ficheiro | O que tem |
|---|---|
| [`biblia.json`](biblia.json) | A Bíblia inteira |
| [`livros/`](livros) | Um JSON por livro |
| [`texto/`](texto) | Um Markdown por livro, para ler |

```json
{ "id": "jo", "nome": "João", "abreviatura": "Jo", "testamento": "NT",
  "capitulos": [ { "capitulo": 3, "versiculos": [ { "n": 16, "texto": "Porque Deus amou…" } ] } ] }
```

Os versículos vêm pela **ordem de leitura**. A numeração segue a da Vulgata; a única falha é Esd 8,3, que a edição não tem (ver [CORRECOES.md](CORRECOES.md)). Usa a ordem do ficheiro e não assumas que `n` é sempre sequencial. Os **Salmos** seguem a numeração da Vulgata (o Salmo 22, «O Senhor é meu pastor», é o 23 da numeração hebraica).
